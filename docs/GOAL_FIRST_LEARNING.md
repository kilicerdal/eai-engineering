# Goal-first learning

Learners describe a goal in their own words, optionally upload/select notes or PDFs, set level/time/weekly frequency/optional date, then review and edit an AI-proposed initial path. Existing materials storage, file limits and excerpt retrieval are reused. Only selected excerpts are sent when generating an outline; source references describe planning context, not verified answer citations.

The plan route uses existing shared origin/rate-limit protections, a 64 KB request cap, bounded input/schema validation, a shared 45-second provider deadline and at most one format repair. It does not create calendar events, guarantee outcomes, predict scores, or claim official exam coverage. The exam-preparation expansion is deferred.

Learners can edit title/overview, edit/reorder/add/remove lessons (3–8), accept their outline, prepare a lesson message in the tutor, explore freely, and mark completion themselves. Level, goal, activity and understanding check are carried into the tutor. Opening a lesson does not submit a message automatically. Material-based answers remain in the separate evidence-aware materials workspace.

Valid plans and self-reported progress persist in local browser storage. Partial invalid edits do not overwrite the last valid plan. Accounts, cloud sync, automatic mastery diagnosis, automatic plan adaptation and calendar scheduling are not implemented. Changes to input settings are flagged and require regeneration to update lesson content. Regenerating replaces the previous outline and clears its progress only after a valid response succeeds; failed/cancelled requests preserve it.

The former four-track planner is labeled Guided Practice, with its actual question-bank scope disclosed.
