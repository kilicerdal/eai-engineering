# Eight tutor guidance refinements — local, unpublished

1. Continued confusion: prepares a smaller, different explanation rather than repetition.
2. Hint ladder: gentle hint, more specific hint, then an explicitly requested worked explanation. Stages advance only when a draft is accepted; nothing automatically sends. Earlier answer text cannot be hidden retroactively.
3. First mistake: asks for actual working when absent, checks the original reasoning and avoids invented errors.
4. Optional understanding check: one unanswered question, waiting for the learner.
5. Compare attempts: selects actual learner messages from the active session, requires chronological order, and asks the tutor to establish comparability before claiming a change. No mastery claims.
6. Sentence clarification: keyboard/touch-accessible exact-text field complements existing direct selection. Rejects absent or overlong text.
7. Uncertainty: asks for supplied inputs, inference, unknowns and one useful next check, without fabricated evidence.
8. Ending: opens the existing editable session checkpoint, focusing “What became clearer? Or what is still open?” Existing reflection, next-step and download behavior preserved.
