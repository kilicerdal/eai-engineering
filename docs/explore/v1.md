# eAI Explore — first local release

One complete lever experience at `/explore/lever`, with a homepage entrance. `/explore` redirects there. Existing homepage artwork, learning features and private repository visibility are unchanged.

## Model

An ideal massless rigid lever uses vertical forces, gravity 9.81 m/s², and no friction or losses. Required effort = mass × gravity × load arm / effort arm. Mechanical advantage = effort arm / load arm. For a 0.1 m load rise, effort travel = 0.1 × mechanical advantage; input and output work are equal. The lift view illustrates geometry, not acceleration or elapsed time. This is neither ancient construction reconstruction nor practical lifting guidance.

Source: [OpenStax, Simple Machines](https://openstax.org/books/college-physics-2e/pages/9-5-simple-machines).

## Interaction and privacy

Controls, presets, comparison, simple/deeper authored explanations and a checked challenge work independently of AI. The server recalculates submitted settings. AI suggestions require explicit Apply; invalid proposals and unapproved source identifiers fail closed. Provider credentials remain server-side. Only the submitted question, current settings and explanation depth enter the AI request; notes and saved explorations do not.

Current setup, notes, comparison, challenge and named snapshots use only `eai-explore-v1` browser storage. Existing notebook keys are untouched. Corrupt storage, quota errors and conflicting writes preserve the original stored copy and keep current work available for export. JSON export is included; import is not part of this release.
