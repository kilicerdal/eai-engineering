# Art Room — private writing and collection refinements

2026-11-22. Local preview: http://127.0.0.1:3052/study/art

This is the approved thirty-five-item package, not a count of all historical Art Room improvements. No commit, push or deployment was requested or performed.

## Implementation ledger

1. **Recover unfinished arguments.** Persistent bounded argument drafts store interpretation, observation, evidence, reconsideration and passage choices separately from saved backups.
2. **Protect concurrent argument edits.** Stored baseline comparison and safe reread prevent newer saves/deletions from being overwritten without review.
3. **Guard painting changes in an argument.** Painting and other-argument selection remain disabled until the active draft is saved or discarded.
4. **Undo argument deletion.** Idempotent bounded restoration preserves newer records with the same identity.
5. **Undo passage deletion.** Both study controls and the passage library support restoring removed bookmarks.
6. **Review linked passage removal.** Identifies saved arguments using a passage; retain dangling references or explicitly detach them. Undo reconnects only unchanged argument versions.
7. **Search arguments.** Queries span interpretation, visible observation, evidence and reconsideration text.
8. **Filter arguments by artwork.** An artwork selector narrows the saved argument library without changing records.
9. **Return focus after saving.** A saved/revised entry is revealed and focused; active list filters reset so the entry is present.
10. **Multiple supporting passages.** Up to five distinct passages; the legacy primary-passage field remains supported.
11. **Comparison draft recovery.** A separate validated comparison recovery store survives refresh and navigation.
12. **Comparison conflict review.** A newer saved note cannot be overwritten until the reader accepts a baseline or returns to the latest copy.
13. **Comparison library.** My Art lists saved pairs and links to their exact comparison URL.
14. **Comparison export and print.** Exports complete private text and both artworks’ references without images; print isolation restores screen disclosure state.
15. **Edit detail-note text.** Revisions preserve the existing note ID and retain other annotations.
16. **Detail draft recovery.** Text, coordinates, side and edited-record baseline survive an interrupted visit.
17. **Reposition a saved detail.** Existing coordinate controls revise the selected note without recreating it.
18. **Explicit annotation sides.** New notes distinguish front, back and paired source photograph. Original coordinates remain unchanged; a missing reverse is never replaced with a front image.
19. **Bulk collection additions.** Select multiple saved works and preview destination memberships before applying.
20. **Copy or move reviewed memberships.** Reports existing/new memberships; applies against a checked collection snapshot. Saved paintings and writing remain intact.
21. **Undo collection-member removal.** Restores original placement where possible without duplicates or removal of newer memberships.
22. **Unique renamed collections.** Creation and rename use normalized name comparison with an explicit retry after validation errors.
23. **Find personal collections.** Searches personal collection names without modifying stored names or membership.
24. **Compare collection overlap.** Shows shared works and works unique to each chosen collection.
25. **Deliberate exhibition restart.** A confirmation panel restarts only the walkthrough; sequence, introduction and notes stay intact.
26. **Paragraph bookmarks.** Existing passage tool can save a specific numbered paragraph with a stable exact anchor.
27. **Identify shortened excerpts.** New bookmarks record truncation and link to full context. Older bookmarks are not falsely claimed to be complete or unchanged.
28. **Compare changed editorial passages.** Public work/paragraph IDs retrieve only current public text signatures and excerpts. Saved excerpts remain untouched when text differs.
29. **Accurate accented highlights.** Normalized matching maps to original string offsets, including distant accented words and punctuation.
30. **Specific notebook empty states.** Distinguishes no saved writing, no matching query, collection selection and writing-type absence.
31. **Specific backup validation errors.** Identifies record type/index and limits without revealing submitted private text or changing the file.
32. **Identify backup scope.** Preview distinguishes original gallery-only files from complete Art Room backups.
33. **Show capacity near actions.** Passage, argument, collection, comparison and per-artwork detail-note limits appear beside relevant tools; safe retries reread current copies.
34. **Cross-browser coverage.** Tracked Chromium/WebKit/Firefox projects. Chromium and WebKit launch and execute checks; Firefox remains blocked by its local profile-folder startup error.
35. **Writing browser-history journeys.** Back, Forward, refresh and canceled in-app navigation across eight editor cases, plus an actual institutional new-tab handoff with a locally stubbed destination.

## Preservation and boundaries

- Old version-1 backups and original gallery-only files remain readable. New optional fields retain multiple passage IDs, paragraph anchors, truncation/signature metadata and detail side. Legacy records are not rewritten on read. Backups exported by this version should be restored with this or a later version to preserve the added metadata; compatibility with an older reader that ignores optional fields is not promised.
- No artwork assets, licensed-image terms, subject gates, original catalogue identities or external services changed. The bounded internal passage-record route reads the site’s public editorial text only. Requests contain public work/section IDs, never private notes or arguments.
- Argument, comparison and detail recovery copies are separate browser records. They are not silently treated as saved writing or included in the saved Art Room backup. Unreadable recovery copies are preserved; failed writes leave editor text available.
- Undo preserves a newer record instead of overwriting it. Collection previews abort safely if memberships change before application.
- No saved-note data is transmitted to AI. Reading exports omit artwork images.
- A bounded 64 KiB JavaScript / 4 KiB CSS allowance is recorded for the package. Image and book limits are unchanged.
